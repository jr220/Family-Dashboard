One-time Google Setup

Paste your Google OAuth Client ID below to connect your calendars and tasks.

How to get your Client ID:
1. Go to console.cloud.google.com → create a project
2. Enable Google Calendar API and Tasks API
3. APIs & Services → Credentials → Create OAuth 2.0 Client ID (Web app)
4. Add http://localhost:8080 to Authorized JS Origins
5. Copy the Client ID and paste above
